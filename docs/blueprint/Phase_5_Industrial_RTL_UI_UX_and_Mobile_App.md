# المرحلة 5: تصميم الواجهة الميدانية وتجربة المستخدم (Industrial RTL UI/UX & Mobile App)

## 1. مبادئ التصميم الصناعي الميداني (Industrial UX Principles)
1. **واجهة عربية أصيلة من اليمين إلى اليسار (Native RTL):** جميع القوائم، البطاقات، شريط الخطوات، ومؤشرات الاتجاه مصممة أصلاً لـ RTL باستخدام خط **Noto Sans Arabic** أو **IBM Plex Sans Arabic** بأوزان واضحة (Bold / SemiBold).
2. **وضع داكن عالي التباين (High-Contrast Industrial Dark Mode):**
   - خلفية داكنة شبه شفافة (`#0B0F19` بنسبة شفافية 85%) فوق بث الكاميرا لضمان وضوح القراءة تحت أشعة الشمس المباشرة أو إضاءة المصانع.
   - ألوان دلالية صارمة:
     - **الكهرماني الصناعي (`#F59E0B`):** للقطع المحددة وأدوات العمل.
     - **الأحمر التحذيري (`#EF4444`):** لمخاطر الضغط العالي والجهد الكهربائي.
     - **الأخضر الزمردي (`#10B981`):** لتأكيد إتمام الخطوة أو مطابقة عزم الشد.
3. **التشغيل بدون يدين أو بالقفازات (Hands-Free & Glove-Friendly):**
   - أزرار لمس كبيرة لا يقل ارتفاعها عن `64px` في أسفل الشاشة (منطقة إبهام اليد) لسهولة الضغط أثناء ارتداء قفازات الصيانة السميكة.
   - التحكم الكامل بالأوامر الصوتية العربية دون الحاجة للمس الشاشة.

---

## 2. تدفق الشاشات (User Flow)
1. **شاشة المسح السريع (Equipment Identification):** مسح لوحة بيانات المعدة (Nameplate OCR) أو اختيار الموديل صوتياً.
2. **شاشة الواقع المعزز الحية (Live AR HUD):**
   - **الشريط العلوي:** اسم المعدة + مؤشر جودة الاتصال + زر كتم/تفعيل الصوت.
   - **منطقة الكاميرا المركزية:** مؤشر التصويب (Reticle) + القناع ثلاثي الأبعاد والأسهم فوق القطعة.
   - **بطاقة التحذير المنبثقة (LOTO Banner):** تظهر باللون الأحمر عند الحاجة لعزل الطاقة.
   - **البطاقة السفلية المدمجة:** رقم القطعة (بخلفية أحادية المسافة LTR وسط النص العربي)، اسمها بالعربية، الخطوة الحالية، وقيمة عزم الشد إن وجدت.
