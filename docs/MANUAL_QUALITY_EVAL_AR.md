# خطة تقييم جودة إجابات أدلة MISBAR

هذه الخطة تختبر الدليلين المفهرسين حالياً من خلال واجهات API الحقيقية، مع فصل نتائج الاسترجاع عن جودة الصياغة.

## التشغيل على الإنتاج

من مجلد المشروع:

```powershell
python scripts/manual_quality_eval.py
```

أو حدد نطاق الواجهة:

```powershell
python scripts/manual_quality_eval.py --base-url https://frontend-production-9dd137e1.up.railway.app
```

أدخل بريد الحساب وكلمة المرور عند الطلب. كلمة المرور تُقرأ عبر مطالبة مخفية، ولا تُكتب إلى سطر الأوامر أو ملف التقرير أو المستودع. يستخدم الاختبار تسجيل الدخول ثم طلبات قراءة للفهارس والبحث والمحادثة فقط؛ لا يستورد أو يحذف أو يعدّل أي دليل أو بيانات جلسة.

يُحفظ التقرير المحلي افتراضياً في:

`docs/test-results/manual-quality-latest.json`

## الحالات التي يجري التحقق منها

| المجموعة | الحالة | المتوقع |
|---|---|---|
| بيانات الأدلة | Siemens وGrundfos | تطابق رقم الوثيقة، الشركة، عدد الصفحات، والطرازات |
| عربي/إنجليزي | «مانع التسرب» و`shaft seal` | الوصول إلى دليل Grundfos، صفحة PDF 9 والصفحة المطبوعة 9 |
| عربي/إنجليزي | «مواصفات وحدة المعالجة المركزية» و`CPU 1214C technical specifications` | الوصول إلى دليل Siemens، صفحة PDF 1132 |
| عزل الطراز | بحث Grundfos ضمن طراز Siemens والعكس | لا نتائج متقاطعة |
| منع التلفيق | رقم/مصطلح غير موجود | لا نتائج غير مسندة |
| الاستشهاد | سؤال وصفي عن كل دليل | رقم الوثيقة ورقم الصفحة وعلامة مصدر موجودة |
| صحة المصدر | علامة مثل `[S99]` غير موجودة | حذف العلامة غير المعروفة من إجابة RAG |
| السلامة التشغيلية | عزم الشد | مقتطفات فقط دون استدعاء نموذج التوليد |
| سلامة النص المسترجع | تعليمات مضمّنة داخل مقتطف | التعامل معها كنص وثائقي غير موثوق، لا كتعليمات للنموذج |

## فحوص الوحدة

أضيفت اختبارات خلفية في `backend/tests/test_manual_quality.py`. شغّلها من مجلد `backend`:

```powershell
python -m pytest tests/test_manual_quality.py tests/test_manual_api.py -q
```

وتشغّل مجموعة الخلفية كاملة عبر:

```powershell
python -m pytest -q
```

## تفسير النتائج وحدود التقييم

- فهرسة النص والبحث الحاليان من نوع BM25 lexical. توسيع المفردات العربية يضيف مقابلات محددة للمصطلحات الواردة في الدليلين؛ وهو ليس ترجمة عامة ولا بحثاً دلالياً متجهياً.
- رقم PDF هو رقم موضع الصفحة في الملف. لا يعرض النظام رقماً مطبوعاً إلا عندما تم التحقق منه صراحة؛ لذلك Siemens يعرض صفحة PDF 1132 فقط.
- مرور الاختبار يثبت الاسترجاع والطراز والاستشهاد وتوجيه طلبات السلامة في الحالات المدرجة، ولا يثبت صحة كل جملة مولدة أو صلاحية تنفيذ إجراء ميداني.
- لا يجوز اعتبار وجود مقتطف دليلاً على مطابقة المعدة الفعلية. يجب مطابقة لوحة البيانات والطراز والمراجعة بواسطة مختص مؤهل.
- تظل قيم العزم والتوصيلات وخطوات الفك والتركيب والعزل خارج توليد RAG التشغيلي، وتبقى خاضعة لبوابة السلامة وقاعدة المعرفة المعتمدة.

## تغييرات هذه الحزمة

1. توسيع عربي/إنجليزي محدود في `backend/app/knowledge/manual_index.py`.
2. اختبارات ثنائية اللغة، فلترة الطراز، التحقق من الصفحات، منع علامة مصدر غير صحيحة، وحظر توليد عزم الشد.
3. مشغّل إنتاج للقراءة فقط في `scripts/manual_quality_eval.py`.
