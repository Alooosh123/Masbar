# دليل استيعاب كتيبات OEM والبحث الموثق — مِسبار

**الحالة:** أول تنفيذ لخط أنابيب PDF محلي  
**المسار البرمجي:** `backend/app/knowledge/manual_index.py`  
**أداة الاستيعاب:** `scripts/ingest_manual.py`  
**واجهات API:** `GET /api/v1/manuals` و`GET /api/v1/manuals/search`

## 1. ما الذي أصبح متاحاً؟

أصبح مِسبار قادراً على استيعاب ملف PDF محلي مصرح بمعالجته، واستخراج النص القابل للنسخ منه، وتقسيم الصفحات إلى مقاطع قصيرة مع الاحتفاظ بمرجع الصفحة.

كل سجل وثيقة يحتفظ بـ:
- الشركة المصنعة واسم الوثيقة ورقمها ومراجعتها.
- عائلة/طراز المعدة ورمز الطراز إن توفر.
- رابط المصدر الرسمي إن توفر.
- بصمة SHA-256 للملف الأصلي.
- عدد الصفحات، والصفحات التي استُخرج نصها، والصفحات التي لم يُستخرج منها نص كافٍ وتحتاج مراجعة لتحديد الحاجة إلى OCR. هذه العلامة ليست حكماً بأن الصفحة ممسوحة ضوئياً؛ فقد تكون صفحة فارغة أو رسماً بلا نص.
- تأكيد حق المعالجة وملاحظة الترخيص/الإذن.
- تاريخ الفهرسة.

كل مقطع يحتفظ بـ:
- معرّف الوثيقة.
- `pdf_page_index`: فهرس صفحة PDF بصفر-based يبدأ من 0.
- `pdf_page_number`: ترتيب صفحة PDF يبدأ من 1.
- `printed_page_number`: الرقم المطبوع في الدليل إذا أمكن اكتشافه من تذييل الصفحة.
- رقم الصفحة المطبوع في الدليل إذا أمكن اكتشافه من تذييل الصفحة.
- عنوان القسم المبدئي.
- نص المقطع ورقمه داخل الصفحة ومعرّفه الثابت.

## 2. ما الذي لا يفعله هذا الإصدار؟

أصبح مسار الاسترجاع مرتبطاً بمولد Cohere في المحادثة:

- استخراج PDF وتقسيمه إلى مقاطع مستقلة مع مراجع صفحات.
- استرجاع BM25/lexical لأفضل خمسة مقاطع مع تضييق اختياري حسب طراز المعدة.
- تمرير السؤال والمقاطع المسترجعة إلى Cohere في وضع RAG مع تعليمات تمنع اختراع الحقائق وتطلب إسناد الإجابة إلى [S1] وما يليها.
- إلحاق قائمة مصادر فعلية بالإجابة تتضمن اسم الوثيقة ورقمها ومراجعتها ورقم صفحة PDF والصفحة المطبوعة عند توفرها.
- عند فشل Cohere أو رفض المخرج، يعود النظام إلى عرض المقاطع الأصلية بدلاً من اختراع إجابة.

هذه مرحلة RAG نصية lexical + generation. وليست بعد منظومة semantic/vector RAG أو Multimodal RAG كاملة.

ما لم يُنفذ بعد:
- Qdrant أو embeddings أو reranking دلالي.
- OCR للصفحات المصورة.
- استخراج جداول العزم آلياً كبيانات هيكلية وحفظ مواقع الخلايا.
- تحليل الصور والرسومات التفجيرية ومخططات الكهرباء والهيدروليك ضمن الاسترجاع.
- Neo4j أو رسم بياني لعلاقات المعدات والقطع.
- اعتماد آلي لخطوات الصيانة أو قيم العزم أو LOTO من المقتطفات.

طلبات العزم وLOTO والفك والتركيب والتوصيل/الأسلاك والتهيئة وإجراءات التشغيل تبقى مقتصرة على الاسترجاع وعرض المصدر، ولا تُحوّل إلى تعليمات تنفيذية مولدة.

## 3. تثبيت الاعتماد

أضيفت المكتبة `pypdf>=7.1.1,<8.0` إلى متطلبات Backend. مصدر الإصدار: <https://pypi.org/project/pypdf/>.

بعد سحب آخر فرع:

```
cd backend
..\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

قبل الاستيعاب، يجب التأكد من أن لديك حق معالجة نسخة PDF محلياً وفق ترخيص OEM أو الإذن الذي حصلت عليه.

- يتطلب الأمر --rights-confirmed صراحةً.
- يتطلب --rights-note وصف أساس السماح بالمعالجة؛ لا تكتب تأكيداً غير صحيح.
- لا ترفع ملفات PDF الأصلية أو فهارسها المحمية إلى GitHub.
- نقطة استيراد PDF متاحة عبر POST /api/v1/manuals/ingest، وتتطلب مستخدماً مسجلاً بدور owner أو admin.
- نقطة استيراد الفهرس المحلي POST /api/v1/manuals/import-index تقبل JSON مطابقاً للمخطط وتسمح بنقل الفهرس دون رفع ملف PDF الأصلي مرة أخرى، وتتطلب الدور نفسه.
- نقطة الاستيراد ترفض أي طلب لا يحمل جلسة مستخدم بدور owner أو admin، حتى إن كان إعداد المصادقة غير مفعل.
- الملف الأصلي يعالج داخل مجلد مؤقت ويحذف بعد الفهرسة؛ الذي يبقى في MANUAL_INDEX_DIR هو فهرس المقاطع النصية فقط.
- بحث المقتطفات وأمر RAG معطلان افتراضياً بواسطة MANUAL_SEARCH_ENABLED=false. وفي الإنتاج يلزم كذلك AUTH_REQUIRED=true حتى يصبح manual_search_available فعالاً.
- تتطلب المصادقة إعداد JWT_SECRET_KEY بطول لا يقل عن 32 حرفاً، وقيم المالك الأولية وفق تعليمات النشر.
- يجب تخزين data/manual_index/ على Volume دائم خاص منفصل عن Volume الجلسات؛ وإلا قد تضيع الفهارس عند إعادة بناء الحاوية.
- رفع المستخدم للكتيب وحده لا يثبت حق إعادة تخزين نصه المستخرج. لا تؤكد الحقوق إلا إذا كنت تملك الإذن/الترخيص الملائم.

## 5. تنفيذ Dry Run

مثال توضيحي لملف محلي. استبدل المسار والبيانات بالقيم المطابقة فعلاً للمستند لديك:

```
python scripts/ingest_manual.py --input ./manuals/grundfos-cr5.pdf --doc-id grundfos-cr-family-model-a --title "Service instructions CR 1, CR 3 and CR 5" --manufacturer Grundfos --equipment-model "Grundfos CR 5 Model A" --model-code "CR 5 Model A" --document-number "96546866 0407" --language en --source-url "https://www.grundfos.com/" --rights-confirmed --rights-note "اكتب هنا أساس الإذن أو الترخيص الفعلي الذي تملكه"
```

بدون `--apply` يعمل الأمر في وضع الفحص فقط ولا يكتب ملفاً.

بعد التأكد من أن الوثيقة والنسخة والموديل ومعلومات الترخيص صحيحة، أضف `--apply`:

```
python scripts/ingest_manual.py --input ./manuals/grundfos-cr5.pdf --doc-id grundfos-cr-family-model-a --title "Service instructions CR 1, CR 3 and CR 5" --manufacturer Grundfos --equipment-model "Grundfos CR 5 Model A" --model-code "CR 5 Model A" --document-number "96546866 0407" --language en --source-url "https://www.grundfos.com/" --rights-confirmed --rights-note "أساس الإذن الفعلي" --apply
```

لا تستخدم `--overwrite` إلا بعد مراجعة الفهرس الموجود والسبب الذي يستلزم استبداله.

## 6. حدود الاستيعاب الحالية

- الحد الأعلى لحجم PDF: 100 MB.
- الحد الأعلى لعدد الصفحات: 2500 صفحة.
- ملفات PDF المشفرة لا تُفهرس.
- إذا لم يجد المستخرج نصاً قابلاً للاستخراج، يرفض الفهرسة ويطلب OCR مصرحاً به.
- إذا احتوى الملف صفحات نصية وصفحات مصورة، يفهرس الصفحات النصية ويُظهر عدد الصفحات التي تحتاج OCR.
- يتم تقسيم كل صفحة إلى مقاطع لا تتجاوز 1800 حرف افتراضياً مع تداخل محدود للمحافظة على السياق.
- يظل رقم صفحة PDF محفوظاً حتى عندما لا يمكن اكتشاف ترقيم الصفحة المطبوع.

## 7. استخدام API

### قائمة الوثائق المفهرسة

```http
GET /api/v1/manuals
```

يعيد بيانات وصفية فقط، ولا يعيد نص الكتيبات.

### البحث

```http
GET /api/v1/manuals/search?q=shaft%20seal&equipment_model=Grundfos%20CR%205%20Model%20A&limit=5
```

كل نتيجة تحتوي مرجع الوثيقة، و`pdf_page_index` و`pdf_page_number` و`printed_page_number` عند اكتشافه، والقسم، ومقتطفاً نصياً قصيراً، ورابط المصدر إن كان موجوداً.

حقول الاستجابة تعلن صراحة:
- `retrieval_method = bm25_lexical`
- `vector_search_enabled = false`

اكتب مثلاً:

اسأل الكتيبات عن معنى diagnostic buffer
ابحث في الكتيبات عن CPU 1214C

عند توفر Cohere واسترجاع مقاطع كافية، ينشئ مِسبار إجابة عربية مرتبطة بالمقاطع ويعرض مراجعها [S1] وما يليها. في الأسئلة التي تطلب إجراءً تشغيلياً أو قيمة عزم أو فكاً/تركيباً أو توصيلاً أو LOTO، يعرض المقاطع والصفحات دون صياغة تعليمات تنفيذية.

## 8. ربط Grundfos CR 5

المصدر الرسمي المدرج في سجل المشروع:

<https://www.grundfos.com/content/dam/local/no-no/page-assets/support/techical-support/teknisk-selvhjelp/documents/teknisk-selvhjelp-vannforsyning/cr-service/Grundfosliterature-79597.pdf>

البيانات التي تظهر في الوثيقة:
- العنوان: Service instructions — CR 1, CR 3 and CR 5.
- الطراز: Model A.
- نطاق التردد: 50/60 Hz.
- الأطوار: 1/3~.
- رقم الوثيقة: 96546866 0407.
- اللغة: English (GB).
- الطول: 19 صفحة.

جدول المحتويات يحدد:
- Type identification: الصفحتان 2–3.
- Tightening torques and lubricants: الصفحة 4.
- Service tools: الصفحتان 5–6.
- Dismantling and assembly: الصفحات 7–13.
- Order of assembly for chambers and impellers: الصفحتان 14–15.
- Drawings: الصفحات 16–19، ويبدأ قسم CR 5 في الصفحة 18.

**قيد المطابقة:** اسم العائلة CR 5 لا يكفي وحده لاعتماد أي خطوة أو عزم. يلزم التحقق من لوحة بيانات المضخة ورمز النوع/النسخة ورقم المنتج ومراجعة الدليل المطابق قبل اعتماد أي معلومة.

## 9. معايير قبول استيعاب كتيب

- [ ] تم التحقق من حق المعالجة والترخيص.
- [ ] تمت مطابقة الشركة والموديل ورمز النوع ورقم المنتج.
- [ ] تم تسجيل رقم الوثيقة والمراجعة واللغة.
- [ ] تظهر أعداد الصفحات النصية والصفحات التي تحتاج OCR.
- [ ] يمكن البحث عن مصطلح معروف وإرجاع الصفحة الصحيحة.
- [ ] يظهر رقم صفحة PDF والصفحة المطبوعة بشكل منفصل.
- [ ] لا تُرفع ملفات PDF أو فهارسها المحمية إلى Git.
- [ ] لا تتحول مقتطفات البحث إلى خطوات صيانة معتمدة تلقائياً.

## 10. الخطوة الهندسية التالية

بعد نجاح استيعاب أول ملف مصرح به واختبار جودة مراجع الصفحات، تكون الخطوات التالية بالترتيب:
1. إضافة OCR اختياري للصفحات المصورة مع إظهار أن النص ناتج من OCR.
2. تطوير محلل الجداول مع حفظ إحداثيات الصف/العمود والصفحة، خاصة جداول العزم.
3. إضافة embeddings وQdrant مع بقاء البحث النصي كمسار fallback.
4. إضافة reranking والتحقق من الطراز/رقم المنتج.
5. بناء مسار مراجعة واعتماد بشري للحقائق الحساسة قبل انتقالها إلى قاعدة الصيانة التشغيلية.

## 11. فحص الملفات المرفقة في هذه المحادثة

تم فحص نسختي PDF المرفقتين باستخدام مسار الاستخراج نفسه، وكانت النتيجة:

| المستند | الصفحات | صفحات ذات نص | صفحات تحتاج OCR | المقاطع المتوقعة |
|---|---:|---:|---:|---:|
| Grundfos CR 1/3/5 — Model A، الوثيقة 96546866 0407 | 19 | 19 | 0 | 21 |
| Siemens S7-1200 System Manual V4.7، الوثيقة A5E02486680-AQ | 1,323 | 1,323 | 0 | 2,176 |

هذه أرقام فحص واستخراج وليست إقراراً بأن الملفات أُضيفت بالفعل إلى فهرس الإنتاج. تُضاف الملفات إلى الإنتاج عبر نقطة الاستيراد بعد تأكيد حق المعالجة.

نطاق Siemens: دليل S7-1200 يتناول عائلة وحدة التحكم PLC وملحقاتها المحددة. ربطه بجلسة لوحة Siemens لا يعني أن كل القواطع أو الكونتاكتورات أو أطراف اللوحة أو مكوناتها مغطاة بهذا الدليل.

نطاق Grundfos: دليل الخدمة يغطي مضخات CR 1 وCR 3 وCR 5 ضمن Model A، ولا يضيف تلقائياً هذه المضخات إلى محرك جلسات الصيانة أو قاعدة القطع المعتمدة في مِسبار.

## 12. استيراد الملفات والفهارس عبر API

يتطلب الطلب مستخدماً مسجلاً بدور المالك أو المدير.

### الخيار الأول: استيراد PDF

POST /api/v1/manuals/ingest

يستقبل الملف الأصلي ويعيد بناء الفهرس داخل الخادم. الملف الأصلي يعالج في مجلد مؤقت ولا يُحتفظ به.

### الخيار الثاني: استيراد فهرس جاهز

POST /api/v1/manuals/import-index

يستقبل ملف JSON تم إنشاؤه وفق المخطط نفسه، ويكتب الفهرس إلى MANUAL_INDEX_DIR بعد التحقق من مخطط ManualIndex وحقوق المعالجة وعدد الصفحات والمقاطع. هذا الخيار أنسب عندما تتم معالجة PDF محلياً مسبقاً، لأنه لا يرسل ملفات OEM الأصلية مرة أخرى إلى الخادم.

الحد الأعلى لحجم ملف الفهرس 15 MiB. لا يمكن استبدال فهرس بالمعرف نفسه إلا عند تمرير overwrite=true بعد مراجعة النسخة الحالية.

### حقول استيراد PDF

- file: ملف PDF.
- doc_id: معرف فريد مثل grundfos-cr-135-model-a.
- title: عنوان الوثيقة كما يظهر فيها.
- manufacturer: الشركة المصنعة.
- equipment_models: طراز دقيق واحد أو أكثر، وتُرسل الحقول المتكررة.
- model_codes: رموز النوع عند توفرها.
- document_number وrevision وlanguage وsource_url: بيانات الوثيقة.
- rights_confirmed=true وrights_note: تأكيد صحيح لأساس حق المعالجة، لا عبارة افتراضية.

بعد الاستيراد، استخدم GET /api/v1/manuals لمراجعة الوثائق، وGET /api/v1/manuals/search?q=shaft%20seal لاختبار الاسترجاع.
